# Netflix Data Analysis Using Python

## Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python to identify content trends and generate meaningful insights.
## Objectives

- Analyze Netflix Movies and TV Shows data.
- Compare Movies and TV Shows.
- Identify the top countries contributing content.
- Find the most common genres.
- Analyze content growth over the years.
- Analyze content ratings.
## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Data Analysis

The project includes:

- Data Cleaning
- Missing Value Analysis
- Duplicate Checking
- Movies vs TV Shows Analysis
- Top Countries Analysis
- Top Genres Analysis
- Year-wise Content Analysis
- Content Rating Analysis

## Key Findings

- Movies make up a larger portion of the dataset than TV Shows.
- The United States has the highest number of titles.
- India is one of the major contributors of Netflix content.
- International Movies and Dramas are among the most common genres.
- Netflix content has grown significantly over the years.
